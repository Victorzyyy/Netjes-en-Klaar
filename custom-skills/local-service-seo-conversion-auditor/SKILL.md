# Local Service SEO Conversion Auditor

Use this skill to make a local service website easier to find, trust, and contact.

## Audit Order
1. Business clarity: what service, for whom, where, and how to contact.
2. Search intent: match pages/headings to what clients search.
3. Conversion path: CTA, phone, form, friction, mobile usability.
4. Trust: operational proof, process, FAQs, service details.
5. Technical basics: metadata, schema, performance, accessibility.

## SEO Essentials
- One clear H1 on the homepage.
- Use service terms naturally: kantoorschoonmaak, vakantiepark schoonmaak, evenementenreiniging, bouwschoonmaak.
- Add location strategy when service areas are known.
- Metadata should mention service + area + brand.
- Use CleaningService schema when appropriate.

## Conversion Essentials
- Phone CTA visible in header on desktop.
- Mobile contact path should be obvious.
- Form should ask only what is needed: name, contact, service, timing, location, message.
- CTA labels should say what happens next.

## Trust Signals
- clear checklist
- known team / point of contact
- time windows
- feedback after cleaning
- one-off or fixed planning
- special handling for events, holiday parks, construction handover

## Mobile UX Checks
- No decorative effect should block form fields or CTAs.
- Headings should not overflow.
- Cards should not become cramped columns.
- Tap targets should be large enough.
- Sticky/header elements should not cover content.
